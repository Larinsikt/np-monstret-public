# NP-Monstret — publik dokumentation

Officiell dokumentation om [NP-Monstret](https://npmonstret.se) — en svensk plattform för förberedelse inför nationella prov, byggd av legitimerade lärare och specialpedagoger.

Det här repot är vår fakta-källa. Här beskriver vi öppet hur plattformen fungerar, hur den är förankrad i Skolverkets riktlinjer (Lgr22 och Gy25), och hur vi hanterar elevdata.
