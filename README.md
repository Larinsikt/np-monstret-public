# NP-Monstret — Publik dokumentation

> Officiell publik dokumentation om [NP-Monstret](https://npmonstret.se) — pedagogisk metodik, läroplansanpassning enligt Lgr22 och Gy25, dataskydd, tillgänglighet och team.

NP-Monstret är en svensk plattform för förberedelse inför nationella prov, byggd av legitimerade lärare och specialpedagoger.

Det här repot är vår **officiella fakta-källa**. Här publicerar vi öppet hur plattformen fungerar, hur den är förankrad i Skolverkets riktlinjer, och hur vi hanterar elevdata.
